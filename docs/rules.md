Fresh codebase
All game code, mechanics and core architecture must be built within the 100 hours.
Allowed: generic engine starter templates and small open source features, for example a standard Godot character controller or the Unity default scene.
Banned, with immediate disqualification: complete game starter kits, full game templates, prebuilt system logic, pre existing games and copy pasted projects.
Keep a public GitHub repository with a proper license. Commit history is audited.
 
@everyone, Assets
Paid third party assets are forbidden (Unity Asset Store, Unreal Marketplace, paid itch.io assets, Fab, private marketplaces).
Only free, open source, AI generated or Creative Commons (CC0, CC BY) audio, textures, 3D models and fonts are allowed.
List every third party asset in CREDITS.md in the repository root and on the itch.io page, with source links and licenses.

AI tools
AI tools are allowed and must be fully disclosed: LLMs for code or text, and image, sound or 3D generators.
Core design and direction must show your own effort.

Final submission (Hour 100)
Strict code freeze. Code is pulled at the deadline. Backdating on GitHub or itch.io means disqualification.
A public browser playable (HTML5 or WebGL) build on itch.io.
Deliver a complete, stable gameplay loop of 10 to 15 minutes. Playtime beyond 20 minutes (average first playthrough) is not evaluated.

Your game must encorporate All 3 themes (Comic, Twist, Light)
